# LegalEase - AI-Powered Legal Document Generator

LegalEase is a full-stack web application designed to generate customized, structured legal agreements and documents using Next.js 15, Tailwind CSS, and the Google Gemini 2.0 API.

---

## 🚀 Features

- **Document Customization**: Supports multiple document types (NDAs, Contractor Agreements, Residential Leases, SLAs, Cease & Desist Letters).
- **Jurisdiction-Aware**: Tailors legal clauses based on specified location or jurisdiction.
- **Instant Preview & Export**: Features real-time generation, one-click text copying, and direct `.txt` file downloading.
- **Modern UI**: Clean, responsive, dark-mode interface built with Tailwind CSS and Lucide React icons.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **AI SDK**: `@google/genai` (Gemini 2.0 Flash)
- **Icons**: Lucide React

---

## 📋 Prerequisites

Ensure you have the following installed on your machine:
- [Node.js](https://nodejs.org/) (v18.17 or higher recommended)
- `npm` or `yarn` / `pnpm`
- A Google Gemini API Key from [Google AI Studio](https://aistudio.google.com/)
